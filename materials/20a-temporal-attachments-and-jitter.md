# TASK-20A: History & Jitter Attachment Configuration

## 1. Concept & Mental Model

### Binding Temporal State
Unlike spatial upscaling, which needs only input color and output target, the **MetalFX Temporal Scaler** requires four synchronized attachments and per-frame subpixel telemetry to perform temporal accumulation:

1. **Color Texture**: Shaded low-resolution scene.
2. **Depth Texture**: 32-bit Reversed-Z depth buffer.
3. **Motion Texture**: Analytical motion vectors ($\mathbf{p}_{\text{prev}} - \mathbf{p}_{\text{curr}}$).
4. **Output Texture**: Full-resolution destination.

### Subpixel Jitter Offsets
MetalFX must know the exact subpixel phase shift applied to the current frame:
```cpp
pScaler->setJitterOffsetX(jitter.x);
pScaler->setJitterOffsetY(jitter.y);
```
Offsets are passed directly in **input pixel coordinates** (values in $[-0.5, 0.5]$ generated by Halton(2,3)).

### Camera Cuts & History Reset (`setReset(true)`)
When a camera cuts to a new scene angle or teleports, historical samples from previous frames no longer correspond to the current view frustum. If temporal history is not invalidated, a severe ghost of the old scene will linger on screen.
Calling `pScaler->setReset(true)` tells the scaler to discard internal history for that frame.

## 2. Camera Cut Detection Mathematics

Let $\mathbf{P}_{\text{curr}}$ and $\mathbf{P}_{\text{prev}}$ be camera positions in world space, and $\mathbf{F}_{\text{curr}}, \mathbf{F}_{\text{prev}}$ be forward view directions:

$$\Delta d = \|\mathbf{P}_{\text{curr}} - \mathbf{P}_{\text{prev}}\|, \quad \cos\theta = \mathbf{F}_{\text{curr}} \cdot \mathbf{F}_{\text{prev}}$$

A camera cut is triggered if:
$$\Delta d > D_{\text{threshold}} \quad \text{or} \quad \cos\theta < \cos(\theta_{\text{threshold}}) \quad \text{or} \quad \text{frameNumber} == 0$$

## 3. Metal & C++ Blueprint

### Temporal Scaler Binding (`src/TemporalUpscaler.hpp`)
```cpp
void prepareTemporalFrame(
    MTLFX::TemporalScaler* pScaler,
    MTL::Texture* pColor,
    MTL::Texture* pDepth,
    MTL::Texture* pMotion,
    MTL::Texture* pOutput,
    simd::float2 currentJitter,
    bool isCameraCut
) {
    // 1. Bind Attachments
    pScaler->setColorTexture(pColor);
    pScaler->setDepthTexture(pDepth);
    pScaler->setMotionTexture(pMotion);
    pScaler->setOutputTexture(pOutput);

    // 2. Set Subpixel Jitter Offsets (in input pixels)
    pScaler->setJitterOffsetX(currentJitter.x);
    pScaler->setJitterOffsetY(currentJitter.y);

    // 3. Set Reset Flag for Camera Cuts / First Frame
    pScaler->setReset(isCameraCut);
}
```
